# Public documents

Place your public CV, papers, presentations, and handouts here. The site uses `cv.pdf` and `resume.pdf`. Replace both sample PDFs before publishing; keep the filenames unchanged and no link edits are needed. The HTML examples are optional starting points for other pages.

From `index.html`, link a PDF with:

```html
<a href="public/documents/cv.pdf">Download CV (PDF)</a>
```

Use lowercase filenames with hyphens. Everything here is public. Remove drafts, sensitive metadata, and private contact details before committing. Publish papers only when you have the right to distribute them.

## Upload or replace your CV and resume

1. Export your documents as PDFs named `cv.pdf` and `resume.pdf`.
2. On GitHub, open this folder and select **Add file → Upload files**. Upload both files and commit. Or replace them locally, then commit and push.
3. Wait for Pages to deploy, then check the CV/Resume toggle and both Open/Download links.

If you use different filenames, update **both** links in the corresponding document panel in `index.html` (search `EDIT DOCUMENTS`). The toggle needs no edits to JavaScript. PDFs are public downloads; there is no visitor upload form.

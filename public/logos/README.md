# Logos

Place favicons, institution logos, and project marks here. `mark.svg` is a generic starter favicon; replace it with your own. Follow the relevant owner's usage permissions for institutional or third-party logos.

## Social icons

`linkedin.svg`, `github.svg`, and `orcid.svg` are from [Font Awesome Free 6](https://github.com/FortAwesome/Font-Awesome/tree/6.x/svgs/brands), by Fonticons, Inc., licensed under **CC BY 4.0** for SVG icons. Original attribution comments are retained in the SVGs; see [the bundled license](FONT-AWESOME-LICENSE.txt). These third-party icons are excluded from the template's MIT artwork license. Brand names and marks belong to their respective owners.

To personalize links, search `EDIT SOCIAL LINKS` in `index.html` and replace the adjacent `href` values with your LinkedIn, GitHub, and ORCID profile URLs. Keep the visible labels; icon images have empty alternatives because those labels already name each link.
